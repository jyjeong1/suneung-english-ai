📱 설치 가이드

Prof.AI를 홈화면에 추가하면 앱처럼 바로 실행할 수 있습니다.

별도 앱스토어 설치가 필요 없습니다.

홈화면에 아이콘을 추가하면 일반 앱과 동일하게 사용할 수 있습니다.

🍎 iPhone / iPad (Safari)

1 Safari에서 Prof.AI 허브를 엽니다.

2 하단 중앙의 공유 버튼 □↑ 을 탭합니다.

3 아래로 스크롤하여 "홈 화면에 추가" ➕ 를 탭합니다.

4 이름을 확인하고 "추가"를 탭합니다.

✓ 홈화면에 Prof.AI 아이콘이 생성됩니다!

🤖 Android (Chrome)

1 Chrome에서 Prof.AI 허브를 엽니다.

2 우측 상단의 메뉴 ⋮ 를 탭합니다.

3 "홈 화면에 추가" 또는 "앱 설치"를 탭합니다.

✓ 홈화면에 Prof.AI 아이콘이 생성됩니다!

❓ 자주 묻는 질문

용량을 많이 차지하나요?

아닙니다. 웹 기반이므로 거의 용량을 차지하지 않습니다.

업데이트는 어떻게 하나요?

자동으로 최신 버전이 적용됩니다. 별도 업데이트가 필요 없습니다.

iPhone에서 Chrome으로도 되나요?

iPhone은 Safari에서만 홈화면 추가가 가능합니다.
